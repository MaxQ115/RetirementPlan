# 退休计划 - 为了自由，为了不上班 🌅

> "Freedom is not free, but it's worth every penny."  
> 专为追求理智财务规划与自由退休同行者设计的交互式财务规划工具。

## 🌟 功能特色

- **现实清醒剂**：分析启动资金、目标金额与无追加投入时的极端年化需求（70.2% 痴人做梦分析）。
- **理智定投推演**：支持动态调整启动资产、每月定投金额、预期 CAGR 与投资年限，实时推演资产增长曲线。
- **动态交互图表**：基于 Chart.js 的资产增长预测与本金对比折线图，并配有离线 Canvas 降级保障。
- **肖申克地道越狱隐喻**：
  - 现金储蓄地道深度图（500W = 500米）。
  - 挥锤打卡记录与快速追加记录。
  - 越狱五重关隘里程碑与自律戒律打卡。
- **现代高雅白底设计**：高对比度清爽界面、优雅微交互、完美适配移动端与桌面端。
